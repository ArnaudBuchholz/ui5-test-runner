Any textual value.

## Syntax

Any string is accepted, with no further constraint.

## Example

The [`pageParams`](../pageParams.md) option takes an arbitrary string appended to the page URL: `--page-params foo=bar&debug=true` (or `-pp foo=bar&debug=true`).
